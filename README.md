# Snake 97

A browser-playable tribute to the classic Nokia LCD Snake game. Built with plain HTML, CSS, and JavaScript, with no dependencies or build step.

## Play

Open `index.html` in a browser, or enable GitHub Pages for this repository to host it as a website.

## Controls

- Arrow keys or WASD: steer
- P: pause or resume
- Touch buttons: steer on mobile
- Swipe on the game board: steer on mobile
- Restart: start a fresh game

Eat food to earn 10 points. The game gets faster as your score rises. Your best score is saved in local storage on your device.

## Files

- `index.html` — complete game and styling in one file.
